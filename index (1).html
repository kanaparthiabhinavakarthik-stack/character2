Deploy to GitHub Pages

Zero build steps. Self-contained single-file architecture.

Why this deploys cleanly

All character sprites, animations, physics, and particle shaders are generated procedurally via HTML5 Canvas. There are zero external image or audio URLs that could break with 404 paths on GitHub Pages.

1

Save this file as index.html

Click below to download the ready-to-deploy HTML file directly or copy the source code.

2

Create a GitHub Repository & Push

Create a new public repository on GitHub (e.g., character-sandbox) and push index.html to the main branch:

git init
git add index.html
git commit -m "Deploy Aegis-07 character sandbox"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/character-sandbox.git
git push -u origin main
3

Enable GitHub Pages

Open your repository on GitHub → Go to Settings → Select Pages in the left sidebar → Under Build and deployment, set Source to Deploy from a branch, choose main / /(root), and click Save. Your playable demo will be live in ~30 seconds!
